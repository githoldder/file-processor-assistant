\subsection{可视化效果}

系统前端展示了多个分析视图，包括：

\begin{itemize}
  \item \textbf{仪表盘概览}：展示用户总数、订单总数、总销售额等关键指标；
  \item \textbf{销售趋势}：按月展示销售额变化趋势；
  \item \textbf{商品分布}：展示不同商品类别的销售额占比；
  \item \textbf{用户活跃度}：展示日活跃用户数变化情况；
  \item \textbf{转化分析}：展示用户从浏览到购买的转化漏斗。
\end{itemize}

\section{结果分析}

实验结果表明：

\begin{enumerate}
  \item Spark 能够在大规模数据集上实现高效的数据处理，百万级数据的分析任务可在 20 秒内完成；
  \item 基于 Flask 的 RESTful API 响应时间在 50ms 以内，满足实时查询需求；
  \item ECharts 可视化图表能够直观展示数据分析结果，辅助用户快速理解数据特征。
\end{enumerate}
