# Sprint 07 PRD — 管理员大数据舱与监控大屏

Last Updated: 2026-06-15 00:30

## Object

将 Analytics 升级为管理员默认的大数据舱：蓝黑风格、全屏优先、业务数据 ECharts 主导、模块入口默认隐藏在四周，通过热键或左右展开箭头进入集群状态、系统 Health、任务监控等管理模块。

## Key Results

- KR-1: 管理员登录后默认看到大数据舱，而不是传统首页。
- KR-2: 大屏默认只显示关键业务指标和图表，模块入口隐藏到四周。
- KR-3: 左右展开箭头或热键可打开对应模块入口。
- KR-4: 大屏数据替换为真实业务/平台 demo 数据，不再使用不相关销售/用户行为数据。
- KR-5: 集群状态与系统 Health 两个管理面板可从大屏进入。

## Admin Big Screen Layout

默认状态：

- 顶部：平台名称、当前模式、刷新时间、整体健康状态。
- 左列：文件处理业务指标、转换成功率、任务队列状态。
- 中央：业务趋势主图、文件转换矩阵或平台流量图。
- 右列：存储、服务健康、失败任务、数据处理管线摘要。
- 底部：最近系统事件、日志摘要或数据源说明。
- 四周隐藏入口：云盘、转换、PDF、集群、Health、任务、报告证据链。

交互方式：

- 左/右展开箭头显示模块入口。
- 快捷键建议：`1` 用户首页、`2` 云盘、`3` 转换、`4` PDF、`5` 集群、`6` Health、`7` 大屏。
- 大屏刷新按钮触发数据重拉取。

## Tasks

### S07-T01: Analytics 改造为蓝黑大数据舱

**目标**: 让 Analytics 成为管理员端默认首页，视觉上足够“答辩大屏”。

**验收口径**:

- 16:9 宽屏下信息密度合适。
- 默认状态没有传统侧边栏遮挡。
- 图表非空、文字不重叠。

### S07-T02: 业务数据替换与图表故事线

**目标**: 用文件处理平台业务数据替代不相关的销售/用户行为数据。

**数据范围**:

- 文件总量、转换次数、转换成功率。
- 文件类型分布、转换格式矩阵。
- 存储使用、任务队列、失败任务。
- Spark/Flask 分析管线输出。

**验收口径**:

- 图表讲的是 CulCloud 文件业务，不讲无关销售业务。
- 每张图有可解释的数据来源。

### S07-T03: 隐藏式模块入口与热键

**目标**: 大屏默认沉浸，模块入口需要时展开。

**验收口径**:

- 默认大屏不被菜单破坏。
- 点击左右箭头可展开模块入口。
- 热键可跳转 1-7 个核心模块。

### S07-T04: 集群状态与 Health 面板接入

**目标**: 管理员从大屏进入监控页面，看到 Docker Compose 集群状态、PM2 服务和 API 健康状态。

**验收口径**:

- Docker Compose 服务状态可展示。
- PM2 服务状态可展示或有明确兜底。
- API 健康状态可刷新。

### S07-T05: 大屏交互增强与拓扑热链接

**目标**: 实现方案 A（时序业务趋势与预处理面板支持弹窗及表格详情）及计算拓扑图节点热链接跳转。

**详细方案与实现细节**:
- **时序业务波动趋势 (Trend Chart)**：右上角增加 `🔍 详情` 按钮，点击后弹出暗黑系 Modal 弹窗。Modal 弹窗左侧渲染放大版 ECharts 趋势图，右侧以表格 (Table) 形式展示原始的历史监控数据。
- **数据预处理质量 (Data Quality Panel)**：右上角增加 `🔍 详情` 按钮，点击弹出 Modal 弹窗。弹窗左侧为清洗历史的汇总图表，右侧为各个文件的原始数据处理详情表格。
- **HDFS/Spark 拓扑图节点点击热链接**：在 `Analytics.tsx` 中的拓扑关系图 `data` 节点配置中，为 HDFS Master 绑定 `targetView: "system-status"`，为 Spark Worker 1 & 2 绑定 `targetView: "task-monitor"`。在 ECharts 实例上通过 `chart.on('click')` 拦截节点点击，调用 `onViewChange` 切换至对应的监控面板。
- **系统 Health 和监控页面白屏与 404 修复**：
  - 调整后端 `tasks.py` 路由定义顺序，将 `@router.get("/{task_id}")` 移动到所有具体路由（如 `/queue-length`、`/recent-failures`）的下方，避免拦截具体路由。
  - 将前端 `useDashboard.tsx` 中的 Context 状态同步（`ctx.setActiveView`）移入 `useEffect` 中执行，避免在 React 渲染阶段更新状态导致死锁白屏。
  - 优化 `SystemStatus.tsx` 和 `TaskMonitor.tsx` 的全局容器样式，适配暗黑大屏背景色、文字对比度及暗色边框。

**验收口径**:
- 点击趋势图和预处理面板详情按钮，可弹出 Modal 详尽查看图表与数据表格。
- 点击拓扑图节点，能流畅切换至系统 Health 或任务监控模块。
- 键盘快捷键、侧边栏点击均可正常打开监控与状态页面，无渲染死锁白屏。

## Acceptance

- 管理员默认进入蓝黑大屏。
- 大屏模块入口默认隐藏，可展开。
- Dashboard 数据语义全部对齐文件处理平台。
- 集群状态、系统 Health、任务监控可以从大屏快速进入。
