\begin{abstract}
  本文设计并实现了一个面向课程大作业场景的 CulCloud 云盘与大数据分析平台。系统围绕学生日常文件处理需求，集成个人首页、云盘上传与分类、文件预览、格式转换、PDF 编辑室、任务监控和管理端数据驾驶舱等模块。前端采用 React 与 TypeScript 构建交互界面，后端通过 FastAPI 提供文件、预览、转换和任务 API，存储层结合 MinIO 与 HDFS，分析层使用 Spark 对上传、转换、下载、预览等遥测行为进行聚合分析。

  针对原型中首页数据不真实、云盘默认列表缺少层次、预览弹窗空间不足以及 PDF Studio 功能不完整等问题，本文完成了真实指标接入、拖拽/点击上传、块状文件分类、专门预览页和 PDF canvas 批注工具的改造。系统支持画笔、图形、箭头、文本、橡皮擦、文本高亮、页面整理和打印导出，能够覆盖课程报告所需的主要办公编辑场景。实验结果表明，该系统能够形成从文件上传、处理、预览、分析到文档证据沉淀的完整闭环。

  \textbf{关键词：}云盘；文件转换；PDF 编辑；Spark；数据可视化；课程大作业
\end{abstract}

\begin{abstract*}
  This paper designs and implements CulCloud, a cloud file management and big data analytics platform for course project scenarios. The system integrates a personal dashboard, cloud-drive upload and categorization, file preview, format conversion, PDF Studio, task monitoring, and an administrative analytics cockpit. The frontend is built with React and TypeScript, while the backend exposes file, preview, conversion, and task APIs through FastAPI. MinIO and HDFS are used for storage, and Spark aggregates telemetry events such as upload, conversion, download, and preview actions.

  To address issues in the previous prototype, including non-explanatory zero metrics, flat file lists, small preview modals, and incomplete PDF Studio functionality, the system introduces live dashboard metrics, drag-and-click upload, block-based file categories, a dedicated preview page, and canvas-style PDF annotation tools. PDF Studio supports pen drawing, shapes, arrows, text, eraser, text highlight, page organization, and print export, covering the main office-editing workflow required by the course report.
\end{abstract*}
