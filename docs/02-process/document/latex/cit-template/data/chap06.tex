\chapter{总结与展望}

\section{工作总结}

本文围绕 CulCloud 云盘与大数据分析平台完成了系统设计、前端实现、文件处理、PDF 编辑室、任务监控和文档工程规划。项目实现了真实首页指标、拖拽/点击上传、块状分类、专门文件预览页、PDF canvas 批注、页面整理、打印导出和管理端遥测分析，能够支撑课程大作业演示和报告撰写。

\section{不足之处}

当前 PDF 编辑室的批注主要在前端渲染和打印导出中生效，尚未完全实现通过 pdf-lib 将批注写回 PDF 坐标。云盘分享、多人协作、权限体系和生产级鉴权也未纳入本次课程项目范围。部分 Office 复杂预览仍依赖后端转换服务稳定性，需要在最终演示前进行端到端验证。

\section{后续展望}

后续工作可从三个方向继续完善。第一，引入 pdf.js、Fabric.js 和 pdf-lib，实现真正的 PDF 坐标级批注写回。第二，补齐政策合规调研、竞品调研、需求调研、系统设计图、UML 图和 UI 截图，形成完整文档证据链。第三，扩展 Spark 遥测分析指标，将上传、转换、预览、失败和下载行为转化为更完整的数据质量评估体系。
