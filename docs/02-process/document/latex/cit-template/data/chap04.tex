\chapter{系统实现}

\section{个人首页真实数据实现}

个人首页通过 \texttt{listFiles(\{recursive: true\})} 统计文件数量与空间占用，通过 \texttt{listTasks} 获取成功和失败任务数量，并展示最近转换任务。若后端接口不可用，页面显示明确错误提示和重试入口，避免将默认零值误认为真实业务数据。

\section{云盘上传与分类实现}

云盘默认页由拖拽上传区和分类文件块组成。用户可拖动文件到页面，也可点击上传文件或上传文件夹。系统根据扩展名将文件归为 PDF、图片、文档、表格、演示文稿、压缩包和其他文件，并使用不同颜色层级帮助用户识别。

\section{文件预览实现}

文件预览从弹窗改为专门预览页。预览页保留返回云盘、下载、预览类型、文件大小和大视口内容区域。PDF 使用浏览器内嵌预览，图片使用自适应展示，文本和 HTML 通过安全 iframe 展示。

\section{PDF 编辑室实现}

PDF Studio 默认进入编辑室。用户可以上传本地 PDF 或从云盘选择 PDF。系统提取页面预览图后，在页面上叠加批注层，支持画笔、高亮、矩形、箭头、文本和橡皮擦。底部缩略图用于选择页面、拖拽排序、旋转和删除页面；右侧导出面板提供云端页面重排导出和浏览器打印导出。

\section{管理驾驶舱与遥测实现}

管理端通过 Spark 对上传、下载、转换、预览、失败等操作进行聚合，形成任务吞吐、失败率、文件类型分布和质量指标。前端使用 ECharts 展示趋势、拓扑、桑基图和质量仪表盘，作为课程报告中的实验截图来源。
