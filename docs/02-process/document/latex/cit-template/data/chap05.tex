\section{算法指标}

文件类型占比可表示为：
\[
  r_i = \frac{n_i}{\sum_{j=1}^{k} n_j}
\]

存储占用率可表示为：
\[
  u = \frac{S_{used}}{S_{quota}} \times 100\%
\]

转换成功率可表示为：
\[
  p = \frac{T_{success}}{T_{success}+T_{failed}} \times 100\%
\]

平均任务时延可表示为：
\[
  \bar{L} = \frac{1}{n}\sum_{i=1}^{n}(t_{complete,i}-t_{create,i})
\]

\section{结果分析}

测试结果表明，CulCloud 已经从静态展示型界面转向真实文件处理平台。首页指标能够反映后端数据状态；云盘默认界面更符合主流云盘产品的信息架构；PDF Studio 具备基础办公批注能力；管理驾驶舱能够为报告提供可追溯的实验截图和数据证据。
