\begin{abstract}
  本文设计并实现了一个面向课程大作业场景的 CulCloud 云盘与大数据分析平台。在大数据与云计算课程项目中，学生经常面临实验材料、大作业报告、课件与本地转换及 PDF 批注工具脱节的痛点，且课程演示缺乏真实的数据流追踪。为此，系统围绕学生日常文件处理需求与管理端监控诉求，集成了个人首页、云盘分类、格式转换、PDF Studio 和 Spark 数据驾驶舱等模块。系统提供可靠的文件预览、快速格式转换与在线 PDF 编辑功能，同时利用轻量级日志采集机制，为后端的离线数据分析平台提供全面而真实的操作轨迹数据。前端采用 React 与 TypeScript 构建交互界面，后端通过 FastAPI 提供服务，存储层结合 MinIO 与 HDFS，分析层使用 Spark 对遥测行为进行聚合分析。

  针对原型中的功能缺口，本文完成了真实指标接入、虚拟目录树前缀算法、Gotenberg 异步转换队列（基于 Celery 与 Redis）以及 PDF canvas 双层批注渲染等关键实现的改造。系统支持画笔、图形、高亮、页面整理和重排导出，覆盖了课程报告所需的主要办公场景。通过 Playwright 端到端测试和单元测试套件的全面验证，系统在高并发转换任务下保持了高成功率，且遥测大屏实现了秒级响应，验证了系统具备良好的高负载稳定性和低响应延迟。本项目的实施不仅大幅提升了课程文档的处理效率，更在开发中将分布式存储、异步队列和大数据计算等核心理论转化为工程实践，具有极高的课程大作业教学与实践价值。

\end{abstract}

\begin{abstract*}
  This paper designs and implements CulCloud, an integrated cloud file management and big data analytics platform tailored for college course projects. Addressing the pain points of fragmented document workflows and simulated metrics in course demonstrations, the system provides an efficient student-oriented workspace and a telemetry-driven administrative cockpit. The frontend is constructed using React and TypeScript, while the backend employs FastAPI to expose file, preview, conversion, and task management APIs. Storage is managed with MinIO using virtual directories, with Gotenberg and a Celery-Redis queue handling asynchronous document transformations. For data analysis, Apache Spark processes user activity logs to render real-time visualizations.

  To resolve initial design flaws such as static dashboard stats, flat file list layouts, cramped preview modals, and basic annotation support, we implemented key features: live operational metrics, drag-and-drop file organization, dedicated multiformat previews, and a canvas-based PDF Studio. The platform supports advanced drawing, highlighting, shape overlays, page organization, and PDF rebuilding. Comprehensive evaluation with Playwright e2e testing and pytest suites demonstrates stable processing under concurrent conversion loads and sub-second telemetry cockpit refreshes. CulCloud not only optimizes personal file-processing efficiency but also bridges theoretical cloud concepts with practical software engineering, demonstrating significant pedagogical value.

\end{abstract*}
