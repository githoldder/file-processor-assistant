# Sprint 05 PRD — 双端 UI 信息架构与角色切换

Last Updated: 2026-06-15 00:20

## Object

完成 CulCloud 前端产品形态拆分：用户端是蓝白风格的文件服务系统，管理员端是蓝黑风格的大数据舱。通过轻量登录/角色切换进入不同视角，避免把业务系统和管理大屏混成一个侧边栏应用。

## Key Results

- KR-1: 用户端和管理员端拥有清晰不同的信息架构、默认首页和视觉风格。
- KR-2: 用户端包含个人数据首页、云盘页、文件转换页、PDF 预览与轻量编辑页。
- KR-3: 管理员端默认进入大数据舱 Dashboard，并可从大屏边缘展开模块入口。
- KR-4: 采用轻量演示鉴权，不引入 Firebase 等外部云服务依赖，保证一周内可控交付。

## Product Split

### 用户端：蓝白服务系统

用户进入后的视角是“享受文件服务”，不展示 Docker、PM2、集群等运维概念。

| 模块 | 页面 | 目标 |
| --- | --- | --- |
| 用户个人数据首页 | `Dashboard` | 展示个人文件、近期任务、转换次数、存储使用量。 |
| 云盘服务 | `MyFiles` | 上传、列表、下载、删除、重命名、文件夹组织。 |
| 文件转换服务 | `ConvertCenter` | 高频格式转换优先实现，强调简单易用。 |
| PDF 预览与轻量编辑 | `PDFStudio` | 预览、合并、拆分、重排、导出。 |

### 管理员端：蓝黑大数据舱

管理员登录后的默认视角是“平台运营与系统监控”，大屏优先于传统业务表单。

| 模块 | 页面 | 目标 |
| --- | --- | --- |
| 大数据舱 Dashboard | `Analytics` | 替代当前首页作为管理员默认大屏，集中展示业务数据和 ECharts。 |
| 集群状态监控 | `SystemStatus` 或新分区 | 展示 Docker Compose/Hadoop/Spark 风格服务状态。 |
| 系统 Health 面板 | `SystemStatus` | 展示 PM2 服务、本地接口 API、Redis/MinIO/Gotenberg/FastAPI 健康状态。 |
| 任务监控 | `TaskMonitor` | 展示转换任务、失败任务、队列长度和最近异常。 |

## Authentication Decision

本 Sprint 不接 Firebase。理由：

- 当前只剩约一周，Firebase 会引入网络、账号、CLI、部署和环境变量管理成本。
- 课程答辩更关注系统闭环、架构解释、数据可视化和证据链。
- 演示版只需要区分 `user` 与 `admin` 两种视角，不需要真实注册、找回密码、三方登录和安全审计。

实现策略：

- 做本地轻量登录页或顶部角色切换入口。
- 预置两个演示身份：`demo_user` 与 `admin`。
- 使用前端状态 + localStorage 保存角色，必要时后端提供一个 mock login API。
- 文档说明：课程演示版使用本地演示鉴权，生产环境可替换为 OAuth/Firebase/Keycloak。

## Tasks

### S05-T01: 角色与路由信息架构

**目标**: 定义 `user` 与 `admin` 两套路由和默认入口。

**交付物**:

- 角色状态设计。
- 用户端/管理员端 route map。
- 导航组件拆分方案。

**验收口径**:

- 用户默认进入个人数据首页。
- 管理员默认进入大数据舱。
- 用户端不出现集群/PM2/Docker 运维入口。

### S05-T02: 轻量登录与角色切换 UI

**目标**: 做一个课程演示足够可信的登录/切换入口。

**交付物**:

- 登录页或登录弹层。
- `demo_user`/`admin` 两种演示身份。
- 退出和切换身份能力。

**验收口径**:

- 刷新页面后能保持角色。
- 未登录时进入登录页或默认演示选择页。
- 管理端入口不会被普通用户导航直接暴露。

### S05-T03: 双主题视觉基线

**目标**: 用户端蓝白，管理端蓝黑。

**交付物**:

- 用户端主题 token 或 CSS 类。
- 管理端大屏主题 token 或 CSS 类。
- 关键页面背景、文字、卡片、按钮、图表容器风格统一。

**验收口径**:

- 用户端看起来像文件服务产品。
- 管理端看起来像运营监控大屏。
- 切换角色后视觉风格明显不同但不割裂。

## Acceptance

- `App.tsx` 具备角色分流能力。
- 用户端和管理员端导航分离。
- 轻量登录/角色切换可演示。
- 不引入 Firebase 或其他外部登录依赖。
