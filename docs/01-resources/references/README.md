# External Reference Source Staging

This directory stores verified external sources for the CulCloud course report.

## Subdirectories

| Directory | Purpose |
| --- | --- |
| `policy/` | Laws, regulations, policy pages, and government sources. |
| `competitors/` | Cloud drive, PDF tool, and document conversion competitor sources. |
| `market/` | Market or usage data used for charts and comparison analysis. |
| `tech-stack/` | Official documentation for React, TypeScript, FastAPI, Redis, Celery, MinIO, Spark, Hadoop, Gotenberg, PDF.js and related tools. |
| `logos/` | Official logo source pages and downloaded assets when license permits. |
| `github-community/` | GitHub repository metadata, stars, releases, issues, and community signals used in the report. |
| `bib-audit/` | Reference verification notes, URL checks, DOI/ISBN/standard-number checks, and BibTeX audit records. |

Every source used in final LaTeX prose should be traceable from this directory, the project codebase, a PRD, a test result, or a rendered screenshot.
