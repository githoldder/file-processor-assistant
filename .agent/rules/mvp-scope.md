# MVP 范围规则

## 核心功能边界

本项目 MVP 严格对应课程要求的五大功能模块：

1. **数据存储与读取**：CSV/JSON/TXT 本地读取 + HDFS 兼容
2. **Spark 数据预处理**：清洗/转换/统计分析
3. **Flask Web 服务**：路由/API/JSON
4. **ECharts 可视化**：看板/柱状图/折线图/饼图/表格
5. **系统附加功能**：数据刷新/图表交互/轻量化部署

## 禁止顺手扩展

- 不增加数据库（课程要求无此项）
- 不增加用户认证/权限（不在要求范围）
- 不增加真实生产环境部署配置
- 不增加非课程要求的数据源
