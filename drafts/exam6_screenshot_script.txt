用途说明：
本文件用于手动完成实验报告截图。每一步都写明需要输入的命令、应该看到的关键结果、建议截图文件名，以及截图插入到 Word 文档中“五、实验过程与结果”的具体位置。

开始前准备：
打开终端，进入项目目录：
cd "/Users/caolei/Desktop/culcloud platform"

Step 1：拉取实验镜像
输入命令：
docker pull chaoliu123/myubuntu:hadoop-mapreduce-lab-topn

Step 2：启动 Hadoop/Hive 实验容器
输入命令：

如果端口被占用或已有同名容器，先输入：

然后重新执行：
scripts/hadoop-image.sh run

收尾清理：
如果实验截图已经完成，可以停止或删除容器，但不要删除镜像：
scripts/hadoop-image.sh stop

如果要删除容器但保留镜像：
scripts/hadoop-image.sh clean

注意：
不要在未确认镜像已推送和可拉取之前执行 docker image prune、docker rmi 或 docker system prune。
