\chapter{相关技术与调研}

\section{政策合规依据}

本系统涉及用户上传文件、文件名、任务记录、预览缓存和转换结果，因此需要参考《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》和《促进大数据发展行动纲要》等政策文件。系统设计中采用最小必要采集、用户文件可删除、预览缓存隔离、任务日志留痕和错误状态可解释等方式，将合规要求映射到具体功能。

\section{云盘与文件处理竞品}

主流云盘产品普遍支持拖拽上传、文件夹组织、文件类型识别、搜索、共享和大视口预览。对课程项目而言，最重要的不是复杂协同，而是让用户快速完成“上传资料、找到资料、预览资料、转换资料、导出资料”的闭环。因此 CulCloud 将首页搜索和通知等未完成的伪功能移除，保留真实队列、失败任务和文件操作链路。

\section{PDF 办公编辑竞品}

PDF 工具类产品通常具有 PDF 阅读器、页码跳转、缩放、文本高亮、画笔、图形、箭头、文本框、橡皮擦、打印和导出等能力。本系统当前通过 PDF 页面图像预览叠加批注层实现轻量编辑，并保留后端页面重排导出能力。后续可引入 pdf.js、Fabric.js 与 pdf-lib，将批注对象按 PDF 坐标写回文件。

\section{核心技术}

\subsection{React 与 TypeScript}

前端采用 React 与 TypeScript 构建模块化界面，主要视图包括 Dashboard、MyFiles、ConvertCenter、PDFStudio、TaskMonitor、SystemStatus 和 Analytics。TypeScript 用于约束接口返回值、任务状态和文件实体，降低前后端对接风险。

\subsection{FastAPI 与任务队列}

后端提供文件、预览、转换、任务和系统健康等 REST API。耗时转换任务通过异步任务记录和 polling 查询状态，前端根据成功、失败和处理中状态展示真实进度。

\subsection{MinIO、HDFS 与 Spark}

MinIO 负责对象存储和下载链接生成，HDFS/Spark 负责课程大数据实验链路。Spark 可对上传、转换、下载、预览等遥测数据按时间、动作和文件类型聚合，生成管理端分析指标。

\subsection{PDF 渲染与批注}

PDF 页面提取由后端服务生成页面预览图，前端在页面图上叠加 SVG/canvas 式批注层。批注对象包括画笔轨迹、高亮轨迹、矩形、箭头和文本，支持在打印导出时同步渲染。
