## 算法公式候选

1. 文件类型占比：\( r_i = n_i / \sum_{j=1}^{k} n_j \)。
2. 存储占用率：\( u = S_{used} / S_{quota} \times 100\% \)。
3. 转换成功率：\( p = T_{success} / (T_{success}+T_{failed}) \times 100\% \)。
4. 平均任务时延：\( \bar{L} = \frac{1}{n}\sum_{i=1}^{n}(t_{complete,i}-t_{create,i}) \)。
5. Spark 聚合：按 `action`、`file_type`、`date` 分组执行 count/sum/avg，支撑用户侧和管理侧指标。

## Python 画图字体约束

中文图表优先使用 macOS `PingFang SC`，脚本中设置 `matplotlib.rcParams["font.sans-serif"] = ["PingFang SC", "Arial Unicode MS", "SimHei"]`，并设置 `axes.unicode_minus = False`，避免中文乱码和负号渲染错误。
