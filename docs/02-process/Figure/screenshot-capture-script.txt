绿果果分布式应用课程大作业截图采集脚本

采集原则：
1. 截图必须服务于最终报告和答辩，不截无关历史页面。
2. 截图前先确认 PM2、Nacos、Gateway、核心服务健康状态。
3. 正式报告截图文件放入 docs/02-process/Figure/screenshots-real。
4. 文件名建议使用 Sxx-英文短名.png，例如 S01-pm2-status.png。

重要修正：
1. docs/02-process/Figure/screenshots 目录中的旧版自动生成模板图不得作为正式报告证据使用。
2. docs/02-process/script/capture_report_screenshots.mjs 只可作为排版草稿或占位核对工具，不可替代真实工具截图。
3. 正式截图必须来自真实终端、真实浏览器控制台、真实 Nacos/RabbitMQ 管理台、真实微信开发者工具或真实测试命令输出。
4. 若某个真实工具因账号、权限、基础库兼容或系统截图权限无法完成，应在证据清单中标记为阻塞项，不能生成仿真页面冒充。

S01-PM2服务运行状态
操作路径：
1. 打开终端，进入项目根目录。
2. 执行 pm2 status 或 pm2 list。
3. 截图要求展示 lgg-nacos、lgg-gateway、lgg-admin、lgg-business、lgg-pay、lgg-notice、lgg-redis、lgg-minio、lgg-ruoyi-frontend 均在线。
建议文件：screenshots-real/S01-pm2-status-real.png

S02-Nacos服务注册中心
操作路径：
1. 打开浏览器访问 http://127.0.0.1:8848/nacos。
2. 进入服务列表。
3. 截图要求展示 lgg-gateway、lgg-admin、lgg-business、lgg-pay、lgg-notice 实例在线。
建议文件：screenshots-real/S02-nacos-services-real.png

S03-Gateway接口动态路由转发

2. 截图工具窗口中的真实响应数据，证明网关成功进行了后端模块的统一动态路由。

S07-微信小程序商品结算UI
