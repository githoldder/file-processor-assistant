# Sprint 06 PRD — 用户端文件服务与转换能力优先级

Last Updated: 2026-06-15 00:25

## Object

完成用户端核心业务闭环：个人数据首页、云盘服务、文件转换服务、PDF 预览与轻量化编辑/导出。按照高频文件转换场景优先实现，保证答辩演示不是空壳 UI。

## Key Results

- KR-1: 用户端蓝白业务系统可以完成上传、查看、下载、删除和任务查看。
- KR-2: 文件转换按频率优先支持 Office/PDF/图片/文本相关场景。
- KR-3: PDF Studio 至少支持预览、合并、拆分/重排和导出中的最小可演示闭环。
- KR-4: 用户端关键操作能产生任务记录，并反哺管理员端大屏数据。

## Module Priority

### P0: 答辩必须演示

| 模块 | 功能 |
| --- | --- |
| 云盘服务 | 上传、列表、下载、删除、重命名或基础文件夹组织。 |
| 文件转换 | DOCX/PPTX/XLSX → PDF，图片 JPG/PNG/WebP 互转，TXT/MD → PDF 或预览。 |
| PDF Studio | PDF 预览、合并、拆分/重排、导出。 |
| 任务记录 | 转换状态、失败原因、最近任务列表。 |

### P1: 有时间再补

| 模块 | 功能 |
| --- | --- |
| 文件转换 | PDF → 图片、图片 → PDF、批量转换。 |
| 云盘服务 | 文件夹拖拽、搜索、排序、容量统计精细化。 |
| PDF Studio | 简单标注、旋转、页码缩略图增强。 |

### P2: 明确不做

- 登录注册的生产级用户体系。
- 复杂协同编辑。
- 在线 Office 编辑器。
- 商业计费/套餐。

## Tasks

### S06-T01: 用户个人数据首页

**目标**: 让用户进入系统后看到个人文件和任务概览，而不是管理员分析大屏。

**交付物**:

- 个人文件数量、最近上传、最近转换、存储占用、失败任务。
- 快捷入口：上传文件、转换文件、打开 PDF Studio。

**验收口径**:

- 页面服务感强，不出现集群/运维术语。
- 指标来自 API 或明确的 mock/demo 数据源。

### S06-T02: 云盘服务演示闭环

**目标**: 确保 MyFiles 页可完成最基础文件管理。

**交付物**:

- 上传、列表、下载、删除。
- 空状态、失败状态、加载状态。
- 文件操作后任务或日志有记录。

**验收口径**:

- 用 2 到 3 个样例文件能完整演示。
- 出错时页面能解释失败原因。

### S06-T03: 文件转换高频能力

**目标**: 按使用频率实现转换功能，优先保证课程演示成功率。

**优先级**:

1. Office → PDF: DOCX、PPTX、XLSX 到 PDF。
2. 图片互转: JPG、PNG、WebP。
3. 文本/Markdown → PDF 或可预览格式。
4. PDF → 图片、图片 → PDF 作为 P1。

**验收口径**:

- 每类 P0 转换至少有一个样例文件演示成功。
- 失败任务能进入任务监控并展示原因。

### S06-T04: PDF 预览与轻量编辑/导出

**目标**: PDF Studio 形成轻量工作台，而不是只显示页面。

**交付物**:

- PDF 预览。
- 合并、拆分或重排的最小能力。
- 导出按钮和任务记录。

**验收口径**:

- 至少完成一次“上传 PDF → 预览 → 操作 → 导出”的演示链路。

## Acceptance

- 用户端四个模块可以从导航进入并完成核心演示。
- P0 转换能力有样例文件验证。
- 用户端业务操作能出现在任务/日志/大屏数据中。
